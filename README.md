Netflix Data Analysis using Python

Internship project, Auspify Technologies (Data Analysis Using Python program, Oct–Nov 2026).
Analysis of the public Netflix titles dataset (8,807 rows, 12 columns) with Python, Pandas and Matplotlib: data cleaning, content type split, country-wise credits, release-year trends, rating and genre analysis, and business recommendations.
Key findings: 69.6% movies and 30.4% TV shows; US, India and UK lead by country credits (credits, not unique titles); 2018 has the most titles by release year; TV-MA is the most common rating; International Movies is the top genre.
Tools: Python 3.13, Pandas, Matplotlib, Spyder.
Structure: one folder per task with scripts and outputs; cleaned dataset in netflix_cleaned.csv; charts in Screenshots; full report in PDF.
